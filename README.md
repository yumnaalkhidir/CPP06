# CPP06

42 School C++ Module 06 — type casting: scalar conversion, serialization, and RTTI-free type ID.

## Concepts covered
- Scalar type conversion (ScalarConverter)
- Serialization (pointer <-> uintptr_t)
- Runtime type identification without dynamic_cast/RTTI keywords

## Exercises
ex00 ex01 ex02 

## Build & run
Each exercise has its own Makefile:
```sh
cd exXX
make
./<binary_name>
```
